# Сайт «Тропинка»

Публичный сайт проекта: https://tropinka-kids.ru/

Репозиторий публикуется через GitHub Pages из корня ветки `main`. Файл `CNAME` содержит привязку домена.

## Структура сайта

- `index.html` — основная адаптивная витрина «Тропинки».
- `vitrina.html` — адрес совместимости; автоматически перенаправляет на главную страницу.
- `skazka-anketa.html` — анкета персональной сказки.
- `den-rozhdeniya-anketa.html` — анкета комплекта дня рождения.
- `vyhodnye-anketa.html` — анкета семейных выходных без экрана.
- `obrazec-skazki.html`, `obrazec-dnya-rozhdeniya.html`, `obrazec-vyhodnyh.html` — демонстрационные образцы.
- `privacy.html` — информационная страница о персональных данных.
- `images/` — иллюстрации сайта.
- `docs/TECHNICAL-SPECIFICATION.md` — техническое задание, границы работ и критерии приёмки.

## Контакты

- MAX для личных сообщений: настроен в главной странице и анкетах.
- Канал MAX: ссылка на публичный канал.
- Telegram: резервный канал связи.
- Email: al-vakarin@yandex.ru.
- Ссылка на сообщество VK не опубликована в настройках сайта: не добавляйте её, пока не подтверждён точный адрес сообщества.

## Как работают анкеты сейчас

Автоматический приём на сервер не подключён. Анкеты формируют текст заявки в браузере; после заполнения посетитель копирует текст и самостоятельно отправляет его через предложенный канал связи. Фотографии, прикреплённые в анкете сказки, нужно приложить к сообщению отдельно. Не обещайте автоматическую отправку или автоматическую оплату, пока соответствующая инфраструктура не подключена и не проверена.

## Продукт «Детский квест»

Карточка квеста ведёт на отдельный сайт Questin: https://alexvakarin88-code.github.io/questin/. Его тарифы и форма заказа находятся на отдельной странице и управляются независимо от этого репозитория.

## Публикация и обновления

1. Изменения в `main` автоматически запускают GitHub Pages, если публикация включена в Settings → Pages.
2. После коммита проверьте результат на https://tropinka-kids.ru/ и отдельно откройте каждую анкету и образец.
3. Если обнаружена проблема, используйте контрольную ветку `backup/before-site-refresh-2026-11-04` для сравнения или восстановления исходного состояния.

## Важно перед коммерческим запуском

1. Проверить и завершить политику конфиденциальности с учётом фактической схемы обработки данных, в том числе сведений о детях и фотографий.
2. Утвердить правовое основание, сроки хранения, доступ, удаление и необходимые согласия.
3. При подключении автоматической отправки использовать защищённый серверный endpoint; не помещать секретные ключи в HTML/JavaScript.
4. Проверить фактическую доступность MAX, Telegram, почты и внешнего сайта квестов.
5. Добавить систему аналитики только после получения идентификатора счётчика и настройки корректного уведомления о сборе данных.
