# Сайт «Тропинка» — GitHub Pages

## Публикация
1. Создайте публичный репозиторий GitHub (например, `tropinka-site`).
2. Загрузите **всё содержимое этой папки** в корень репозитория: `index.html`, остальные HTML-файлы, `privacy.html`, `favicon.svg`, `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, нажмите **Save**.
5. Дождитесь завершения публикации в **Actions**. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Настройки проекта
- Главная страница: `index.html` (витрина из исходного `vitrina.html`).
- Все анкеты настроены на ручной приём: сайт формирует текст, который посетитель копирует и отправляет самостоятельно. Автоматической отправки на сервер нет.
- В ссылках политики конфиденциальности используется `privacy.html`.
- Для анкет MAX настроен на существующую ссылку-приглашение канала «Тропинка»; Telegram и email оставлены как запасные контакты.
- Карточка квеста ведёт на внешний проект `https://alexvakarin88-code.github.io/questin/`.

## Перед публичным запуском
Проверьте, что внешняя страница квеста доступна, контакты актуальны, а ссылка-приглашение MAX работает. Политика на `privacy.html` — базовый информационный шаблон, а не юридическое заключение: до сбора данных детей дополните её сведениями об операторе, сроках хранения, правовых основаниях и применимых требованиях. Не принимайте реальные анкеты до этой проверки.
